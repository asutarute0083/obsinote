# ObsiNote — セットアップ手順

Obsidian Vault へクイックメモを作成するPWAです。

---

## ファイル構成

```
obsinote/
├── index.html          ← メインアプリ
├── manifest.json       ← PWA設定
├── sw.js               ← サービスワーカー（オフライン対応）
├── icon.svg
└── icon-maskable.svg
```

---

## GitHub Pages でホスティング（推奨・無料）

1. **GitHubアカウントを作成**（未作成の場合）  
   https://github.com

2. **新しいリポジトリを作成**  
   - リポジトリ名: `obsinote`（任意）
   - Public に設定

3. **ファイルをアップロード**  
   GitHub の画面から「Add file → Upload files」で  
   このフォルダの全ファイルをアップロード

4. **GitHub Pages を有効化**  
   Settings → Pages → Source を `main` ブランチのルートに設定 → Save

5. **URLが発行される**（数分後）  
   `https://あなたのユーザー名.github.io/obsinote/`

6. **スマホのChromeでそのURLにアクセス**  
   → メニュー（⋮）→「ホーム画面に追加」でアプリとしてインストール

---

## アプリの使い方

### 初回
1. アプリを開く
2. 「フォルダを選択する」をタップ
3. ObsidianのVaultフォルダを選択（または直接Inboxなどのサブフォルダ）
4. 権限ダイアログで「許可」

### 日常使用
1. アプリを開く（ホーム画面のアイコンから）
2. メモを入力（これがファイル名になります）
3. 「保存する」をタップ → `.md` ファイルが生成されます

### 設定（フォルダアイコンをタップ）
- **保存先サブフォルダ**: Vault内のサブフォルダを指定（例: `Inbox`）
- **ファイル名に日付を付ける**: ON にすると `2026-05-07 メモ.md` の形式に

---

## 生成されるファイルの形式

```markdown
---
created: 2026-05-07T15:30:00
aliases:
tags:
---
---

## 関連ノート
-   
```

ファイル名 = 入力したメモのテキスト（例: `買い物リストを確認する.md`）

---

## 注意事項

- **HTTPS が必要**: `file://` では動作しません。GitHub Pages 等で必ずHTTPS配信してください
- **Android Chrome** で動作確認済み
- フォルダの権限は再起動後に再確認が必要な場合があります（その際は再度フォルダを選択）
